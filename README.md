# 32_EmployeePayrollSystem_RU-26-00645_1O_ShivamVishwakarma
A console-based Object-Oriented Python Payroll System that calculates net salaries from basic pay, overtime, and role-based bonuses while applying PF and tax deductions. Built using inheritance (Manager extending Employee), input validation, and file handling to save all generated payslips persistently to payroll.txt.
